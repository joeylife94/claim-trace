# ClaimTrace v1.0 Proof Assets

These assets are the external proof package for the frozen v1.0 controlled-pilot workflow.

## Provenance

The screenshots and demo recording in this directory were generated by the PR-visible `V1-07 Proof Package` workflow from the committed deterministic two-document seed and current application code. They are not hand-authored mockups.

The first Korean-font-corrected capture was executed on PR #31. The workflow installs a Korean-capable Noto CJK font before launching Chromium so Korean claim text is visible in the captured proof.

The workflow re-runs the deterministic runtime on every relevant PR head and verifies the capture inventory before a proof-packaging PR can be merged.

## What this proves

- the current web/API/PostgreSQL stack can execute the frozen deterministic workflow;
- analytical results expose source navigation rather than detached generated text;
- comparison remains bounded to the chosen reference document;
- decomposition output and persisted human review are separate product states;
- the proof can be regenerated from repository code and committed deterministic seed data.

## What this does not prove

- legal correctness, infringement, validity, novelty, equivalence, inventive step, or patentability;
- general patent retrieval quality beyond the committed synthetic regression corpora;
- semantic entailment merely because a citation resolves to stored source text;
- OCR/scanned-PDF support;
- current real-local-model quality: V1-07 did not rerun Ollama because no local endpoint was available on the GitHub-hosted runner.

For current executed metrics, workflow evidence, and release closure state, see the root `CLAIMTRACE_V1_MASTER.md`.
